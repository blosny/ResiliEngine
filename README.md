# ResiliEngine 🚀

**ResiliEngine**, Servis Odaklı Mimariler (SOA) için geliştirilmiş, Yapay Zekâ destekli bir mikroservis dayanıklılık analiz sistemidir.

## 🛠️ Teknoloji Yığını

- **Backend:** Node.js (NestJS)
- **AI Service:** Python (FastAPI)
- **Database:** PostgreSQL
- **DevOps:** Docker, GitHub Actions (CI/CD)
- **Management:** Jira (Kanban/Agile)

## 🏗️ Mimari Yapı

Proje, mikroservisler arasındaki iletişimi simüle ederek kontrollü hatalar enjekte eder ve oluşan sonuçları Yapay Zekâ modelleri ile analiz ederek mimari iyileştirme önerileri sunar.

## 🚀 Nasıl Çalıştırılır?

```bash
docker-compose up --build
```
